# 🌍 HoI4 Localization Tool

Автоматизированный инструмент для пакетного перевода файлов локализации Hearts of Iron IV (.yml) с сохранением структуры и игровых маркеров.

---

## 🚀 Основные возможности

* **Интеллектуальный перевод:** Поддержка нескольких движков (Google Translate, DeepL, MyMemory) через `deep-translator`.
* **Защита синтаксиса Paradox:** Автоматическое экранирование и сохранение игровых плейсхолдеров:
    * Переменные и форматтеры: `$VALUE$`, `$$`, `[GetTag]`, `[?value|%G0]`
    * Цветовые коды: `§R`, `§W`, `§!`, градиенты `§0`–`§9`
    * Иконки и кадры: `£money`, `£GFX_army|1`
    * Экранирование: `\n`, `\t`, `\"`
* **Гибридная архитектура:** Использование Java через `JPype` для сложной обработки строк и асинхронные запросы `aiohttp` для ускорения сетевых операций.
* **Умное кэширование:** База данных SQLite хранит все выполненные переводы, экономя трафик и время при повторном запуске.
* **Продвинутый GUI:** Интерфейс на `tkinter` с логами в реальном времени, прогресс-барами и предпросмотром перед сохранением.

## 🛠 Технические требования

Для корректной работы проекта необходимы:

1.  **Python 3.9+**
2.  **Java JDK 11+** (для работы Java-сервиса через JPype)
3.  **Зависимости:** Устанавливаются с exe, либо
    ```bash
    pip install -r requirements.txt
    ```

## ⚙️ Особенности форматирования (Важно)

Инструмент формирует файлы по требованиям HOI4:
* **Языковая база:** В начало каждого выходного файла записывается соответствующий заголовок (`l_english:`, `l_russian:` и т. п.); имя файла заканчивается на `_l_<язык>.yml`.
* **Поддерживаемые цели:** Выбираются только встроенные базы HOI4, в том числе бразильский португальский `braz_por`.
* **Структура:** Ключи локализации не переводятся; значения записываются в одну строку, а игровые маркеры сохраняются.
* **Кодировка:** Файлы записываются в `UTF-8 BOM`, требуемой игрой для локализации.

## 📦 Установка и запуск
Скачайте exe и скачайте HoI4Translator.jar и переводите, 
### Либо
1.  Клонируйте репозиторий.
2.  Убедитесь, что `HoI4Translator.java` скомпилирован или доступен для загрузки через JPype.
3.  Запустите основной скрипт:
    ```bash
    python hoi4_translator.py
    ```

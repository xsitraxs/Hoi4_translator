# Как проверить инструмент, если Hearts of Iron IV не установлена

Игра для работы переводчика **не нужна**. Инструмент читает `.yml` из папки мода и пишет `.yml` в другую папку — сама игра в этом не участвует. Нужна она только для двух необязательных вещей: переиспользования официальных переводов (поле «Ваниль») и проверки результата в запущенной игре.

Ниже — три способа убедиться, что всё работает, по возрастанию «настоящести».

---

## 1. Проверка без перевода: `--dry-run`

Ничего не переводит, не пишет и не требует интернета. Разбирает файлы так же, как переводчик, и показывает, на чём он бы споткнулся.

```bash
python hoi4_translator.py --cli --src examples/demo-mod --dst /tmp/out --target ru --dry-run
```

Ожидаемый вывод:

```
  localisation/english/demo_events_l_english.yml: 7 ключей
  localisation/english/demo_units_l_english.yml: 3 ключей

Итого: файлов 2, ключей 10
```

Коды возврата: `0` — всё разбирается, `1` — есть проблемы. В отчёте видно номера битых строк, дубликаты ключей и незакрытые `§`.

Чтобы увидеть, как выглядят проблемы, испортите копию демо-мода: уберите кавычку в одной строке или продублируйте ключ.

---

## 2. Прогон на демо-моде из репозитория

В репозитории лежит [`examples/demo-mod`](../examples/demo-mod) — маленький мод, в котором специально собрано всё, что ломает машинный перевод: `$STATE$`, `[GetPlayer.GetTag]`, `£army_experience|1`, цвета `§Y…§!`, экранированные кавычки и `\n`. Плюс [`examples/demo-vanilla`](../examples/demo-vanilla) — «мини-ваниль» с официальным русским переводом двух строк, чтобы проверить переиспользование.

**Из интерфейса:** «Оригинал» → `examples/demo-mod`, «Перевод» → любая пустая папка, «На язык» → Русский. Поле «Ваниль» → `examples/demo-vanilla/localisation`. Поле «Глоссарий» → `examples/glossary.tsv`.

**Из консоли** (нужен интернет — Google/MyMemory отвечают без ключа):

```bash
python hoi4_translator.py --cli \
  --src examples/demo-mod \
  --dst /tmp/demo-out \
  --target ru --engine Google \
  --glossary examples/glossary.tsv \
  --vanilla examples/demo-vanilla/localisation
```

Что должно получиться в `/tmp/demo-out/localisation/russian/`:

* файлы называются `*_l_russian.yml`, внутри первая строка `l_russian:`, кодировка UTF-8 с BOM;
* `infantry_division` и `armored_division` переведены **не движком**, а взяты из «ванили» (`Пехотная дивизия`, `Танковая дивизия`) — их не должно быть в запросах;
* во всех строках на месте `$STATE$`, `[GetPlayer.GetTag]`, `£army_experience|1` и `§Y…§!`;
* если движок испортит маркер, файл не запишется (по умолчанию), а ключ попадёт в отчёт `hoi4_translator_report_*.csv`.

## 3. Настоящий мод без покупки игры

Локализация мода лежит в Steam Workshop, но её исходники часто есть на GitHub — их можно взять без игры и без Steam:

* **Kaiserreich** — крупнейший мод, локализация в открытом репозитории;
* **Millennium Dawn**, **The New Order** и другие крупные проекты тоже публикуют исходники.

Порядок: склонировать репозиторий мода, взять из него папку `localisation` (или её подпапку `english`), прогнать `--dry-run`, затем перевод на копию. Мод при этом не нужен — нужны только файлы.

Альтернатива без GitHub: любой переводчик модов, у которого в описании есть ссылка на исходники, или папка `localisation` из архива, который автор выложил отдельно.

## Как проверить качество, не запуская игру

1. **Предпросмотр** (галочка «Предпросмотр перед записью») — показывает первые 1000 строк до записи, их можно править прямо там.
2. **Отчёт прогона** — `hoi4_translator_report_<дата>.json` и `.csv` рядом с папкой перевода: сколько строк записано, сколько взято из ванили, какие строки заменены оригиналом и почему.
3. **Формат** — инструмент сам проверяет то, на чём игра ломается: незакрытые `§`, потерянные `$…$` и `[…]`, лишние кавычки, физические переносы строк внутри значения, BOM, заголовок `l_russian:`.
4. **Повторная проверка** — прогоните `--dry-run` по **результату**: все файлы должны читаться, дубликатов быть не должно.

## Что всё-таки требует игры

* **Поле «Ваниль»** — без установленной игры нечего индексировать. Оставьте его пустым: всё остальное работает как обычно, просто строки из базы будут переводиться движком.
* **Проверка в самой игре** — в глаза и на пропущенные ключи. Заменить её может любой сторонний валидатор локализации (например, HOI4 Localisation Checker или CWTools), они тоже не требуют запуска игры.

## Готовые команды для копирования

Проверить демо-мод (без интернета):

```powershell
python hoi4_translator.py --cli --src examples/demo-mod --dst "$env:TEMP\demo-out" --target ru --dry-run
```

Перевести демо-мод (нужен интернет):

```powershell
python hoi4_translator.py --cli --src examples/demo-mod --dst "$env:TEMP\demo-out" `
  --target ru --engine Google --glossary examples/glossary.tsv `
  --vanilla examples/demo-vanilla/localisation --quiet
```

Проверить свой мод без игры:

```powershell
python hoi4_translator.py --cli --src "C:\path\to\mod\localisation\english" `
  --dst "C:\path\to\out" --target ru --dry-run
```
